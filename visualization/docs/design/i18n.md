# 前端界面本地化

前端固定交互文案由 `visualization/src/i18n/` 负责。`zh-CN` 是固定默认语言，当前支持 `en-US`。语言是项目 Presentation 配置的一部分，由后端 `PresentationService` 持久化；`uiPrefsStore` 只保存服务端确认值和当前待提交 patch。连接地址、token、导航位置和业务数据不参与语言选择。

## 文案所有权

React 组件中的按钮、标题、空状态、加载状态、tooltip、placeholder 和无障碍标签使用稳定 message ID，通过 `useI18n().t()` 在渲染时读取。非 React controller 对需要长期显示的固定提示使用 `message(id, params)`，由 `LocalizedText` 在显示时解析；直接使用 `t()` 只适用于调用边界的即时文本。

`UiText` 只有两种形态：固定文案描述 `{ id, params }`，或已经属于外部事实的普通字符串。它不包装业务对象，也不把用户输入、Agent/模型正文、文件正文、路径、ref、配置值、模型/provider/action 名称或原始诊断放入字典。语言切换只刷新显示投影，不重挂载页面、不重发业务请求、不清空草稿。

字典按前端显示 owner 分组维护：`common`、`settings`、`chat`、`trace`、`runtime`、`workspace`、`home`、`memory`、`history`、`context`、`resources` 和 `presentation`。两种语言必须拥有相同的稳定 ID 和插值参数；新增固定 UI 文案同时补齐两种语言。未登记的固定 ID 是开发错误，不能依赖另一种语言的 source fallback。

## Settings catalog

ConfigCatalog 不复制到字典。字段使用 `field.path`，document 使用完整 `documentSet/documentKind/path`，collection 使用稳定 `id`，choice 使用字段路径与 `value` 作为显示身份。文案表放在 `catalog/zh-CN.ts`；`catalog/index.ts` 只返回不改变原对象的显示投影：中文有登记时使用前端说明，英文使用后端当前 source，未知身份回退 source。搜索同时匹配 source、当前语言投影和稳定路径，命中仍定位原字段；翻译不会改变 path、value、类型、约束或配置事实。

动态 group/surface 标题保留后端 source，前端固定导航分组另用 message ID。凭据按 catalog 的 group/surface 身份分组，覆盖普通对象与按 ID 定位的对象列表；标题变化不改变分组 key。无引用和跨组共享是前端固定分类，用 UiText 在渲染时显示。不同 ID 的同名分组不会合并。

后端正常改写字段说明或新增字段、choice，不要求前端同步修改才能显示；若既有字段的业务含义改变，则应同步审阅已有翻译。Phase 绑定控件的空选项只表达使用默认任务链，不重复维护后端默认任务 ID。

## 协议摘要与动态内容

稳定的 Endpoint error code、运行状态和少量前端生成状态可以在 `protocol/` 中提供摘要。未知 code/value 使用原始后端 message 或原值；details、ref、模型文本和 Observation 原文保留。翻译摘要不参与控制流，逻辑始终比较 code/value 等结构化事实。

Cycle 的三个阶段统一称 Phase。Action 结果顶层 `stage` 描述结果产生的处理环节，详情中显示其协议摘要；它不在 failure 内，也不能用来推导 Cycle Phase。行动摘要的 `kind=plan/result` 只区分展示内容，`executionState` 仍表达执行状态。原始结果与导出保持协议值。

## 验证

`src/i18n/index.test.ts` 验证两种语言的 key/插值契约、合并前重复 ID、默认语言、catalog 身份投影、未知条目回退和协议摘要。`switching.test.tsx`、Settings、问答、Workspace、Trace 和 Presentation 测试验证已挂载内容切换时不丢草稿、不重复读取、不改变请求 payload 或 Toast/Inspector 生命周期。测试只断言稳定协议、结构和代表性显示，不锁定可编辑 catalog、模型、provider、prompt 或用户正文。

运行结果与浏览器观察范围记录在执行计划中。2026-11-03 的 FakeEndpoint + Edge 观察涉及问答、Trace、Settings 与 MemoryGraph；旧记录中的 Session graph 为误记，该记录也不代表 Tauri 桌面验收。
