# 前端界面本地化

前端已接入本地化的固定交互文案由 `src/i18n/` 负责。`zh-CN` 是默认语言，`en-US` 是当前支持的英文语言。语言事实属于项目 Presentation 配置，`uiPrefsStore` 只保存服务端确认值和当前待提交 patch；连接地址、token、导航位置等客户端信息不参与语言选择。

Shell、连接页、Settings 和主要功能页已有部分文案接入双语显示，仍有固定语言的普通控件、状态、校验和提示。UiText 支持显示时翻译，当前主要用于 Presentation 保存错误和部分 History/Context 标题；Trace 标题、连接与 Home 的部分 Toast 尚未迁移。Settings 搜索已随 locale 重新计算。完整迁移及正常切换验收由 [双语界面收尾计划](../../../docs/analysis/20261103-前端双语界面收尾执行计划.md) 跟踪。

`core.ts` 负责纯翻译和 UiText，`locale.ts` 读取现有偏好投影，`react.tsx` 订阅语言；catalog 的中文说明位于 `catalog/zh-CN.ts`，`catalog/index.ts` 提供显示投影。它们不创建第二份业务配置。

## 文案所有权

- React 组件中的按钮、标题、空状态、加载状态、tooltip、placeholder 和无障碍标签使用稳定 message ID，通过 `useI18n().t()` 读取。字典按 `common`、`settings`、`chat`、`trace`、`runtime`、`workspace`、`home`、`memory`、`history`、`context`、`resources` 和 `presentation` 分组维护。
- 非 React controller 需要立即显示时可使用 `t()`；需要保存并继续显示的固定提示使用 `message(id, params)`，避免提前翻译后冻结语言。插值参数不拼入 message ID。
- ConfigCatalog 的 `field.path`、document 的 `documentSet/documentKind/path`、surface/group/collection 的 `id` 和 choice 的 `value` 是翻译身份。中文字典只覆盖确有稳定语义的身份，未知身份返回后端 source 文本。
- 项目、用户、Agent 和模型产生的正文，以及 Action semantic、模型/provider/action 名称、配置值、路径和引用都直接显示；这些动态内容不进入 UI 字典，也不需要额外包装。
- Endpoint 稳定错误 code 和运行/Action 状态 value 可在 `protocol/` 中提供固定摘要；目前 `tStatus` 用于状态栏，`tError` 和 `tActionState` 尚无正式页面消费者，不能据其单测宣称页面已接入。原始 message 和 `details` 仍是诊断事实，未知 code 不做文本猜测。

新增固定 UI 文案时，同时在 `messages/zh-CN` 和 `messages/en-US` 增加同一个 ID。新增 catalog 字段时只需按稳定身份补中文映射；在补齐之前应能正常回退 source 文本。测试检查字典 key 集合、身份映射和 fallback，不逐项锁定经常变化的模型、provider、prompt 或 Action catalog 内容。

文案投影只改标题、说明与 choice label，不改 path、value、类型或约束。后端仅改源措辞时，英文显示新 source，已登记中文保持翻译；改变字段身份或业务含义时，前端绑定和中文说明仍需同步。fallback 保证已进入页面的未知条目可读，不承诺未知 surface 自动拥有编辑页面。

## 验证

`src/i18n/index.test.ts` 验证合并后的双语 key 集合、ConfigCatalog 身份映射、未知条目回退、choice value 和协议摘要映射。Interface 页面测试验证语言保存；controller 测试覆盖通用保存、失败与连接隔离。当前 TypeScript、Vitest 100 个文件/884 个测试及 Vite build 已通过，但这些不证明全局双语完成。

复核发现 common/settings 每种语言有 11 个重复 ID，被对象展开覆盖；现有 key 集合测试未发现这一问题。还需在合并前检查重复、保留插值契约，补齐已显示提示/抽屉/问答草稿等正常切换用例。业务测试应验证编辑、提交、只读和原文保留，不以旧语言文字不存在作为唯一行为证据。
