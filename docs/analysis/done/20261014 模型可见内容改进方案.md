# 模型可见内容改进方案

**状态**: pending  
**日期**: 2026-10-14  
**目标**: 系统性改进 tinysoul/assets 和 tinysoul/prompts 中的模型可见内容，使其更好地引导 Agent 理解架构、灵活思考、主动探索，同时保持清晰易读。

---

## 一、当前问题分析

### 1.1 现有内容的主要问题

**过于严谨和防御性**
- 大量使用 "must"、"do not"、"required"、"only" 等硬性约束
- Phase 引导像是在执行清单，而非引导思考
- 例如：Phase1 引导过度关注 milestone/todo 维护流程，掩盖了"理解当前状态、选择行动方向"的核心

**缺少启发性和鼓励性**
- 没有明确鼓励探索、创造力、主动提问、多方向尝试
- 没有引导何时使用 core.ask、如何结合多层语境
- 没有引导使用意图标注 [赞同]/[提问] 等

**Action Catalog 语义不够清晰**
- 部分 domain/action 的 selection_hint 过于简短
- use_when/avoid_when 不够明确，examples 缺失或不够典型
- 部分 description 过于技术化，缺少业务语义

### 1.2 用户期望的行为模式

- 主动提出问题，有想象力和创造力
- 引导、启发思考和深入交流，主动提出自己的看法
- 鼓励充分理解、探索；鼓励检索网络信息和知识
- 鼓励遇到问题时主动询问用户意见（core.ask）
- 鼓励在不同方向上尝试，避免一条路走到死，及时反思和推理
- 引导使用意图标注如 [赞同]、[提问]、[反对]、[建议]、[执行]
- 引导结合当日语境、工作上下文、长期记忆、Home 知识经验、用户和自己的身份等来推理和行动
- 分步骤、耐心有序完成任务
- 小步探索/小步修改，迭代完成

## 二、改进范围与策略

### 2.1 改进原则

1. **语气转换**：从命令式"must/do not"转向引导式"可以/建议/鼓励/考虑"
2. **保持清晰**：不增加冗余，每条引导都有明确目的和可操作性
3. **启发思考**：用"为什么"和"考虑什么"引导推理，而不是列举步骤
4. **明确工具**：具体说明何时使用 core.ask、core.context.inspect、意图标注等
5. **结合语境**：明确引导利用 Context、Memory、Home 等多层语境
6. **保持架构一致**：改进不改变现有模块职责、数据流或协议

### 2.2 改进层次

```
Layer 1: 核心身份与行为原则 (assets/common/home/agent/)
  ├── identity/soul.md     ：核心价值观、行为模式、表达方式
  ├── identity/identity.md ：个人身份
  ├── AGENT.md            ：角色、行为准则、协作方式
  ├── context/background.md   ：Background 使用说明
  ├── context/turn-trace.md   ：TurnTrace 使用说明
  ├── context/working.md      ：Working 使用说明
  └── context/using-context.md：(新增) Context 综合使用引导

Layer 2: Turn 级别引导 (tinysoul/prompts/agent/)
  └── user.py ：User Turn 整体引导

Layer 3: Phase 级别引导 (tinysoul/prompts/kernel/)
  ├── loop.py    ：Phase1/Phase2 引导
  └── guidance.py：(可选新增) 可复用的通用引导文本

Layer 4: Action Catalog 语义 (assets/common/configs/action/catalog/)
  ├── core/domain.toml      ：core domain 语义
  ├── core/actions/*.toml   ：ask/answer/reason 等 action 语义
  ├── workspace/domain.toml ：workspace domain 语义
  ├── workspace/actions/*.toml ：各 workspace action 语义
  ├── memory/domain.toml    ：memory domain 语义
  ├── ...                   ：其他 domain/action

Layer 5: Action Skill mount (assets/common/home/skills_action/)
  ├── core/answer.md         ：core.answer 的局部 Skill
  ├── workspace/inspect.md   ：workspace.inspect 的局部 Skill
  ├── workspace/search.md    ：workspace.search 的局部 Skill
  └── ...                    ：其他 action 局部 Skill
```
