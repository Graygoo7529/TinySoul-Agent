# TinySoul 检索统一内容流与来源契约执行计划

日期：2026-09-27；基线：`d4d9c8b`。状态：`done`。

## 1. 目标及已确认决策

沿用唯一 Action 执行内核、模型用途 binding 与 `source + steps + page`。Agent 自主决定 query/backlinks/directory 来源或 refs/result 输入及 filter/select/rerank 组合；实现/provider/model 在用途配置内选择。修订贯穿来源、真实内容、候选操作、结果分页、配置与说明，不保留平行旧协议。

- Reflection 通用 Home Search/Inspect 读取 effective Home；Background 基线和 review/diff 仍由各自 owner 管理。R3 已接受，不作代码修复。
- LLM 同次输出候选 ID 与允许为空的 basis_ids；非空依据必须属于实际输入的该候选片段。空依据不表示失败，不强迫低相关 rerank 候选编造正向证据。
- JEV 逐候选 Score，不增加 basis Choice；Embedding 返回真实贡献单元。各种实现如实记录实际输入覆盖，不伪造相同的依据能力。
- MCP 保留真实工具定义上的 literal/regex query；directory → select/rerank 不依赖词面命中，不增加向量索引。
- refs 读取指定入口及 fragment，保留输入顺序。Home top 的精确 refs 读取 SKILL.md；query/directory 的 top 聚合不改变 Link 读取含义，result 才复用此前完整聚合集合。

## 2. 完整契约与实现设计

### 2.1 内容与投影

ContentUnit 是带真实 ref、位置和类型的不可变原文单元，覆盖属于候选及其各次投影；SearchEvidence 只引用单元和范围，记录 lexical/embedding/真实关系/模型指认。SearchCandidate 持身份、属性与单元，CandidateSet 持顺序、来源覆盖和操作事实。取消“从 evidence 反向生成正文”和“页面截断修改快照覆盖”的实现。

共享内容投影生成模型输入及页面。片段保留单元与子范围映射；模型短 ID 只指向实际给出的片段。来源完整性、快照覆盖、实际模型输入覆盖、页面覆盖各自记录，全文/摘录/metadata 使用有限类型。模型选择不输出改写原文，框架通过依据 ID 取回快照原文。

模型投影保证当前每个成员参与，可明确摘录长正文；总预算包含 Context、criterion、指导、问题/协议与序列化输入。超预算反馈 scope_required，不隐式删成员、不自动摘要、不新增内部循环。Embedding 依据实际向量输入记录覆盖。

模型指认优先进入页面，来源命中随后补充；混合 query 的两条通道各有片段空间，避免 lexical 覆盖 semantic evidence。普通预览与命中/判断依据分开标记。分页限制展示成员数，最终集合完整保留；深读仍使用 owner Inspect/read/describe。

### 2.2 操作、结果与生命周期

filter/select 为稳定子集；rerank 为全排列；没有 steps 合法。每步 criterion 独立，Context 使用该请求的一次快照。新请求可带新的 Context 重评同一 result；显式 exclude_refs 取代隐式历史黑名单。

SearchView 冻结完整最终集合。翻页只读快照；result 保留成员、顺序、内容和原来源完整性/通道覆盖，但重新建立本请求 evaluation。旧分数、basis、step_index 不成为本次模型事实。旧视图仍保留自己的事实，无需累积评估历史。

保留 Turn/profile 与 SDK generation/day lease、Action 总期限和取消；辅助模型调用不解除 Inspect 保护。失败沿既有有限 SearchFailure 及 owner 模块边界归类，不建立新的恢复状态机。

### 2.3 来源、匹配与属性

owner 规范身份/fragment、建立元数据与候选资格，在正文读取前执行 where/exclude。refs 保序去重，query 按通道排序融合，directory/backlinks 使用 owner 稳定顺序。反链必须来自真实边，来源正文和链接位置共同进入快照。result 排除只比较冻结身份，不检查磁盘。

Home 先聚合 Skill top 与 resource_types，再判断 where；不能先删掉不同后缀正文。Memory、Context、Workspace 日期等属性声明为明确类型，schema、解析、来源资格及 filter 共用一个比较契约，不手写相互不一致的 supported/ordered 列表。

匹配发生在原始内容，切片只负责披露。Workspace 原生逐行 literal/regex matcher 作为 query 通道实现，返回未被 page/top_k 裁剪的匹配成员、位置和真实上下文；SDK 与 Action 仅保留同一 search 入口。其他来源复用公共匹配与候选设施；公共 engine 不按 action_id 特判业务。

Memory DocumentQuery 显式发布 document_ref 变体；parser/schema 的 scope 默认、query 语法、属性比较保持一致。非文本目录资源可提供 metadata，不能宣称已读取或理解正文。

### 2.4 配置、观测与清理

action.retrieval 使用整体 object，含点 Action ID 保持原子 map key，加载/生成/PATCH/重载一致；移除旧拆分树 wildcard/递归兼容。保持已有模型用途及向量缓存所有权。

Observation 复用 search_id、step_index 与既有 task_id/call_id，明确 LLM 和专用模型调用对应哪一步；query 通道标为来源阶段。无新日志或审计存储。

删除 Workspace 第二套外部搜索结果和无消费者 top_k 配置；移除 memory_daily 配置及旧测试要求。同步 Action 帮助、Skill、design、AGENTS 和 Endpoint 的 capability/schema、SearchPage、配置编辑与观测说明；不修改前端代码。

## 4. 必要行为验收

1. 混合 query 保留双方有效候选，深层语义命中贯穿模型输入与页面，lexical 不否决 Embedding。
2. LLM basis 属于实际给出的候选片段；空依据合法；错误依据局部失败。JEV 不伪称依据；Embedding 覆盖与贡献一致。
3. 多步组合保持 select/filter 稳定子集及 rerank 全排列；本次各步统计和模型调用可关联。
4. refs 纯读、filter、rerank 均合法；顺序/去重/fragment 正确；Home top 不扩大到深层全文。
5. Home 聚合 resource_types 资格不裁正文；反链仍是实际来源资源。
6. Workspace 行锚点、跨内容单元文本均命中，行列位置正确；SDK/Action 同路径，无旧 top_k 先截断。
7. 日期比较及 schema/parser 一致；Memory document query 有明确 schema。
8. excluded 来源正文不占读取预算；result 排除不读文件。
9. result 保存来源覆盖，派生请求不冒充旧 evaluation；翻页及 result 的来源准备无文件和模型重调；result 的显式新模型步骤按请求执行，原视图不变。
10. metadata、摘录、全文以及 snapshot/model/page 覆盖分别真实；预算不足不伪造完整结果。
11. action.retrieval 原子 map 的加载、整体修改、保存重载、标准/开发生成一致；旧补偿解析与 memory_daily 无消费者项清除。
12. MCP 词法 query 与 directory 语义发现共享同一管道；Reflection effective Home 保持接受边界。
13. 既有向量缓存、Inspect 保护、生命周期与失败分类不回退。

共享契约在其 owner 测试一次，插件只补差异路径；不固化实现逐句快照。先运行聚焦测试，再 Fast，完成前必须运行 scripts/test.ps1 -Suite Full 与 scripts/typecheck.ps1。采用既有 TinySoul 环境，必要时设置 TINYSOUL_PYTHON；本地替身验证协议与数据流，不把它当成真实 provider 效果验证。

### 5.4 整体意图与边界核对

1. 六个高层函数与 refs/result 输入使用唯一有限管道。模型实现仍是用途配置，Action executor、总期限、Context、Turn/SDK lease 和模型服务 owner 没有复制。
2. 内容只有 owner 的事实及一次查询快照；证据引用范围，投影不修改快照。共享能力位于 kernel/retrieval 和 infra/model_services，插件仅实现自身身份、范围、属性和原文来源。
3. query 独立召回，filter/select 稳定约束，rerank 全排列；分页有界展示且保留完整成员。新 Context 可重新判断，不增加隐藏检索黑名单或多轮自动摘要。
4. 引用与运行生命周期维持既有归属，反链来自真实边；辅助模型不解除 Inspect 保护；来源/模型失败和模块边界延续原有分类，没有新增恢复链或调度器。
5. 配置、类型、帮助、当前设计和接口投影已交叉核对。历史 r4 归档不被改写，原复核的旧行号和复现保留为历史证据。本计划完成不代表开放检索质量已由真实模型评测证明。

正常主线未发现未落实条目或需要重新讨论的语义冲突。仍有明确产品边界：候选模型与页面内容有界，依据不是正确性证明；超预算须由 Agent 缩小范围，完整正文仍通过 Inspect/read/describe 渐进读取。
