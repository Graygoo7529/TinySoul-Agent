## 3. Owner 反馈与传递

WorkspaceContractError 已有可选 feedback。AgentHomeContractError 与 JobRequestError 使用同样的明确字段，默认空字符串；异常诊断 message 与模型反馈分别维护。Execution 的既有合并 catch 优先使用 `exc.feedback`，无明确反馈时保留现有通用提示。

```diff
-except (JobRequestError, WorkspaceContractError, AgentHomeContractError):
+except (JobRequestError, WorkspaceContractError, AgentHomeContractError) as exc:
     return _failed(
         execution,
-        prompt_text.THE_EXECUTION_REQUEST_IS_UNAVAILABLE_OR_INVALID,
+        exc.feedback or prompt_text.THE_EXECUTION_REQUEST_IS_UNAVAILABLE_OR_INVALID,
         "invalid_request",
     )
```

Execution 结果仍为 `invalid_request / execution.action / CHANGE_REQUEST`。core.job.status/stop 也优先使用 Jobs owner 的反馈，保持原失败分类。没有已整理反馈的普通异常不直接使用 str(exc)；Home runtime-copy、IO、不变量和 Job 监督错误继续进入既有 Runtime bridge。

## 4. 完整反馈文案与落点

以下每条替代对应 Execution 失败中原有的 `The execution request is unavailable or invalid.`，一次失败只返回对应文案。

| 失败条件 | 模型反馈 | owner 落点 |
| --- | --- | --- |
| Workspace 资源不存在 | Workspace resource does not exist. Check the ref or create the resource first. | storage/reconcile.py 的资源缺失分支 |
| Workspace 资源不是文本 | Workspace resource is not a text file. Choose a text resource. | inspection/reader.py 的 read_text |
| Workspace/Home UTF-8 解码失败 | The referenced file is not readable as UTF-8 text. Use a UTF-8 text file. | 各 owner 的文本读取失败分支 |
| Home 内容不存在或已删除 | Home content is unavailable. Choose an existing Home resource. | engine.py 的 _runtime_read_path |
| Home 资源引用类别错误 | This operation requires a Home resource ref: home:resource/<space>/<path>. | refs.py 的资源引用格式与 engine.py 的 _resource_ref |
| resource 形式实际指向 Home top 文件 | This is a top-level Home file. Choose a Home resource file for this operation. | engine.py 的既有 top 文件识别分支，避免只重复 ref 格式 |
| 显式 cwd 不存在或不是目录 | cwd_ref must point to an existing Workspace directory. Omit it to use the Job directory. | WorkspaceEngine.prepare_execution |
| Job 不在当前 Turn 中可用 | Job is not available in this Turn. Use a job_id from the current Turn. | JobRegistry._owned |
| Job backend 能力不匹配 | This Job belongs to a different capability. Use the controls for that Job's capability. | JobRegistry.backend |
| Turn 活动 Job 达到上限 | This Turn has reached its limit of {limit} live Jobs. Wait for a Job to finish or stop one before starting another. | JobRegistry.start，使用实际 per-turn capacity |
| 保留结果容量已满 | Job result capacity ({capacity}) is full. Finish this Turn before starting more Jobs. | JobRegistry.start，使用实际 retained capacity |

Workspace/Home 自己声明资源反馈，不依赖 Execution 的参数语义。cwd_ref 本来属于 Workspace 执行目录准备接口，因此在那里说明。固定句子和纯文本容量函数保持短小，避免回显原始参数、物理路径、异常链或文件正文。

进程无法启动的反馈维持已知事实；本次不根据底层错误猜测原因，不调整进程生命周期或新增错误码。活动容量和保留结果容量给出不同建议，因为等待只能释放活动执行位置，不能清除本轮已保留结果。
