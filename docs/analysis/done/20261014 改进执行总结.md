## 三、改进效果预期

### 核心改进的预期效果

**已完成的核心改进**应该能够显著改善 Agent 行为：

1. **更主动的探索和询问**
   - soul.md 和 AGENT.md 强调主动提问、探索、尝试
   - using-context.md 教会如何有效利用 Context
   - 预期：Agent 会更主动地使用 Context、inspect/search 能力

2. **更合理的小步迭代**
   - 所有层级（soul、AGENT、user guidance、phase guidance）都强调小步骤
   - 预期：Agent 会避免一次性完成所有工作，转而分多个 Cycle 推进

3. **更精准的 Action 选择**
   - 所有 domains 的 selection_hint 更具体
   - Core 和高频 actions 的 semantic 更详细引导
   - 预期：Phase1 domain 选择和 Phase2 action 选择更准确

4. **更灵活的尝试和调整**
   - 强调"受阻时尝试不同方向"
   - 预期：遇到失败时会分析原因，调整策略，而非重复相同尝试

### 待完成改进的预期效果

剩余 42 个 actions 的 semantic 改进属于**锦上添花**：
- 进一步提升 Action 选择精准度
- 减少无效或错误的 action 调用
- 但核心行为模式已由当前改进确立
