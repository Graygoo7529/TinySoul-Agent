官方资料（2026-10-22 核对）：

- [文本生成模型](https://platform.qianwenai.com/docs/developer-guides/getting-started/text-generation-models)、[Qwen3.8-Flash](https://platform.qianwenai.com/docs/developer-guides/getting-started/latest-model)：上下文、输入能力与模型能力范围。
- [上下文缓存](https://platform.qianwenai.com/docs/developer-guides/run-and-scale/context-cache)：显式断点、隐式缓存和 TTL。

两套模板各自新增 `configs/llm/models/qwen.toml`，沿用现有 family 文件自动加载和编辑机制：

| 内部 ID | family | adapter | provider | 远端模型 | 上下文 |
| --- | --- | --- | --- | --- | --- |
| `qwen-max` | Qwen | `anthropic-messages` | `qwen` | `qwen3.8-max` | 1,000,000 |
| `qwen-flash` | Qwen | `anthropic-messages` | `qwen` | `qwen3.8-flash` | 1,000,000 |

内部 ID 不带版本、使用连字符；两个模型均不折叠。provider 声明用户指定的 Chat 与 Messages 两种 endpoint，共用 `QWEN_API_KEY`。与已有可选 Claude/Gemini provider 一致，standard/development 中均默认禁用，填写凭据并启用后再选入任务链。此次不修改运行目录和任务链。

配置语义：

- 思考强度候选为 `low / medium / xhigh`，默认选择服务端默认档 `xhigh`；`high/max` 属于远端映射别名，不重复列为独立档位。
- 不填写 `thinking`，使用 Qwen 默认开启思考的行为；不配置官方已不推荐的新接入预算参数。关闭时可显式选择 `disabled`。`sampling = "omit"` 使用模型默认采样，不让通用任务温度覆盖它。
- `native_replay = "signed"` 复用 Messages 有序 block 回放，包括 thinking 与工具调用。Qwen 返回空 signature，此处表示既有原生 block 模式，不声称 Qwen 提供 Claude 密码学签名；`replay_prefix_binding = false` 不引入未经文档要求的 Claude 前缀约束。
- 显式缓存默认选择 Context 的 Background/Trace 累计前缀，TTL 为 5 分钟。候选仅开放已确认的 `explicit` 和 `5m`，不把 Anthropic 顶层 automatic 与 1h TTL 当作 Qwen 已确认能力；移除显式缓存配置后，服务端仍可使用自身的隐式缓存。不建立本地缓存资源或额外 key 管理。
- 能力声明覆盖文本、图片字节输入、JSON object、工具调用、推理输出和缓存。未单独验证远端图片 URL，所以未声明 `image_remote_url`。JSON object 复用任务提示与 `ResponseInterpreter`，不伪造原生 JSON Schema 支持。
- 不添加模型输出预算覆盖，输出预算继续由现有任务设置传递。API 的 `max_tokens` 包含思考与正文，不能将模型最大输出能力误当每次调用的固定预算。

## 通用 adapter 边界

当前通用 `anthropic-messages` 可以执行上述配置，无须为 family 新建类或分叉请求映射。候选声明收窄远端能力：thinking 仅 enabled/disabled，不允许 adaptive/between_tools；thinking display 候选为空，不暴露 Claude 专属显示档位；工具选择使用 auto。

一个已确认的编辑限制：通用 catalog 将显式 `thinking = "enabled"` 解释为 Anthropic 手动思考，要求同时配置 `thinking_budget_tokens`；Qwen 的现代接入可以仅用 effort。本次默认不填写 thinking，实测思考正常开启，不需要 budget。若之后要求在前端显式选择 enabled 也完全不使用 budget，应先与维护者讨论 Qwen 专用 adapter 或校验归属调整，再实施；不能未经确认放宽所有 Anthropic 模型的校验，也不能把 adaptive 当作 enabled 的别名。

Qwen 的兼容 Messages endpoint 不提供 Models API，因此前端已有“读取能力”功能不能作为它的候选来源；此次使用明确写入 TOML 的候选配置。
