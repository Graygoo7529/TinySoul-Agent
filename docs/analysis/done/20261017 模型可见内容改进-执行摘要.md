## 核心改进点

### 1. 语气转换

**之前**：命令式、防御式
```
"You MUST reconcile..."
"Do NOT claim work without..."
"is mandatory"
```

**现在**：引导式、启发式
```
"First, reconcile..."
"Then, consider: what does the current goal need?"
"When blocked, reflect on the limiting condition..."
```

### 2. 行为引导

**新增核心行为**：
- ✅ 主动提出有见地的问题
- ✅ 遇到不确定时先探索再询问
- ✅ 以小步迭代推进复杂工作
- ✅ 受阻时在不同方向上尝试
- ✅ 及时反思和推理
- ✅ 发挥想象力和创造力

### 3. Action 引导

**每个 action 现在都有**：
- `use_when`：3-5条具体使用场景
- `avoid_when`：2-4条避免场景和替代方案
- `examples`：2-4个具体实用例子
