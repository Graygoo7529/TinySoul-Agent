## 执行计划总览

本计划旨在优化 Settings 页面的视觉统一性和交互细节，提升配置管理体验。

**核心原则**：
- 基于实际 store 结构（useConfigDraftStore + useSettingsUiStore）
- 不重复已有组件（ObjectEditorLayout、FieldRow、controls 等）
- 聚焦视觉打磨和交互细节优化
- 严格遵守 AGENTS.md 设计边界

**修订说明**：
原计划基于假设的 `useSettingsStore` 结构，与实际代码不符。本版本完全重做，基于以下实际架构分析：

### Settings 实际架构

**后端**（`tinysoul/infra/config/`）：
- `descriptors/`：配置项元数据（类型、约束、分组）
- `sources/`：配置来源（project TOML、dotenv 等）
- `editing/`：配置编辑事务（ConfigController、Transaction）
- `documents.py`：Configuration 数据模型
- `validation.py`：配置校验

**前端核心 Store**（`visualization/src/features/settings/draft/`）：
```typescript
// store.ts - 唯一全局配置 store
interface ConfigDraftState {
  saved: Configuration;           // 磁盘配置
  active: Configuration;          // 运行中配置
  catalog: SettingsCatalog;       // 字段元数据
  presets: PresetSummary[];       // 预设列表
  drafts: Record<string, DraftEntry>;  // 本地草稿
  stale: Record<string, true>;         // 基线变更标记
}

// Configuration 是扁平结构
interface Configuration {
  sources: ConfigSource[];
  fields: Record<string, ConfigField>;  // 扁平字典，如 "llm.providers.openai.enabled"
  activity: ConfigActivity;
}
```

**前端 UI Store**（`visualization/src/features/settings/uiStore.ts`）：
```typescript
interface SettingsUiState {
  focusedPath: string | null;    // 当前聚焦字段
  searchQuery: string;            // 搜索关键词
  expandedSections: Set<string>;  // 展开的区域
}
```

**已存在的完整组件**：
- `ObjectEditorLayout`：左列表/右详情布局
- `FieldRow`、`FieldSection`：字段布局
- `Toggle`、`TextInput`、`SelectInput`、`StringListEditor`：基础控件
- `SettingsDraftChip`：草稿状态芯片
- `SettingsBottomBar`：底部操作栏（Apply/Reload）

**数据流**：
```
后端 Configuration → HTTP GET → useConfigDraftStore
  → projectCollection (投影为结构化对象) → 各页面
  → 用户编辑 → store.setValue/deleteValue → drafts
  → draftOperations → HTTP POST /api/v2/config/apply
```

## 背景分析

### 当前状态

Settings 架构已经非常完整：
- ✅ 完整的配置管理系统（后端 infra/config）
- ✅ 清晰的前端 store（useConfigDraftStore）
- ✅ 完善的草稿机制（drafts + stale + rebase）
- ✅ 丰富的页面组件（20+ 配置页面）
- ✅ 统一的编辑模式（ObjectEditor、FieldRow、controls）

### 真实改进空间

经过系统性代码核实，Settings 不需要大规模改造，只需要：

1. **视觉统一性不足**
   - 各页面间距、圆角、阴影不完全一致
   - 缺少统一的 Design Tokens
   - Hover/Focus 效果不统一

2. **Draft 状态展示不够明确**
   - `SettingsDraftChip` 只显示"N 个草稿"
   - 缺少影响范围展示
   - 底部栏没有 Draft 详情

3. **Stale 处理体验不佳**
   - 每个字段单独显示 adopt/keep 按钮
   - 缺少批量处理机制
   - 多个 stale 时操作繁琐

4. **集合编辑可以增强**
   - 缺少搜索/过滤（列表长时不便）
   - 缺少批量操作（如批量禁用）
   - 拖拽排序未实现（可选）

function DraftOperationItem({

  onDiscard

  operation: ConfigOperation;

      <button
        onClick={onDiscard}
        className="p-1 hover:bg-surface-3 rounded transition-colors"
        title="放弃此修改"

        <X size={12} />
      </button>
    </div>
  );
}

### 3.2 创建 StalePanel 组件

新建文件：`visualization/src/features/settings/StalePanel.tsx`

```typescript
export function StalePanel() {
  const store = useConfigDraftStore();
  const [expanded, setExpanded] = useState(false);
  
  const staleCount = Object.keys(store.stale).length;
  
  if (staleCount === 0) {
    return null;
  }
  
  const handleAdoptAll = () => {
    // 删除所有 stale entries
    const staleKeys = Object.keys(store.stale);
    store.resetEntries(staleKeys);
  };
  
  const handleKeepAll = () => {
    // 清除 stale 标记（保留草稿）
    store.clearStale();
  };
  
  return (
    <div className="mx-4 mt-4 border border-yellow-500/30 bg-yellow-500/10 rounded-lg overflow-hidden">
      <div className="flex items-center justify-between px-4 py-3">
        <div className="flex items-center gap-2">
          <AlertTriangle size={16} className="text-yellow-500" />
          <span className="text-sm font-medium text-fg-base">
            配置文件已更新，{staleCount} 个草稿需要处理
          </span>
        </div>
        
        <div className="flex gap-2">
          <button
            onClick={() => setExpanded(!expanded)}
            className="px-3 py-1.5 text-xs hover:bg-yellow-500/20 rounded transition-colors"
          >
            查看详情
          </button>
          <button
            onClick={handleAdoptAll}
            className="px-3 py-1.5 text-xs hover:bg-yellow-500/20 rounded transition-colors"
          >
            全部采纳新值
          </button>
          <button
            onClick={handleKeepAll}
            className="px-3 py-1.5 text-xs bg-yellow-500/30 hover:bg-yellow-500/40 rounded transition-colors"
          >
            全部保留草稿
          </button>
        </div>
      </div>
      
      {expanded && (
        <div className="border-t border-yellow-500/30 px-4 py-3">
          <div className="space-y-2">
            {Object.keys(store.stale).map(path => (
              <StaleEntryItem 
                key={path} 
                path={path}
                onAdopt={() => store.resetEntries([path])}
                onKeep={() => store.clearStale([path])}
              />
            ))}
          </div>
        </div>
      )}
    </div>
  );
}

function StaleEntryItem({ 
  path, 
  onAdopt, 
  onKeep 
}: { 
  path: string; 
  onAdopt: () => void; 
  onKeep: () => void;
}) {
  const store = useConfigDraftStore();
  const draft = store.drafts[path];
  const saved = store.saved.fields[path];
  
  return (
    <div className="flex items-start gap-2 text-xs bg-surface-1 rounded p-2">
      <div className="flex-1 min-w-0">
        <code className="text-fg-faint">{path}</code>
        <div className="mt-1 space-y-0.5">
          <div className="text-fg-faint">
            草稿值：<span className="font-medium text-fg-base">{formatValue(draft?.value)}</span>
          </div>
          <div className="text-fg-faint">
            新基线：<span className="font-medium text-accent">{formatValue(saved?.value)}</span>
          </div>
        </div>
      </div>
      
      <div className="flex gap-1">
        <button
          onClick={onAdopt}
          className="px-2 py-1 hover:bg-surface-3 rounded transition-colors"
          title="采纳新值（放弃草稿）"
        >
          采纳
        </button>
        <button
          onClick={onKeep}
          className="px-2 py-1 bg-accent/20 hover:bg-accent/30 rounded transition-colors"
          title="保留草稿"
        >
          保留
        </button>
      </div>
    </div>
  );
}
```
