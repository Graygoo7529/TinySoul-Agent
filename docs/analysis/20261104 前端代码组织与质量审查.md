## 3. 命名与语义

1. **同名冲突**：`settings/editors/controls.tsx`（1259 行，草稿控件族）与 `settings/models/controls.tsx`（564 行，模型页行控件）同名不同义——导入方只能靠路径分辨。建议其中一个改名（如 editors/ 为 draftControls，models/ 为 modelRows），或各自按职责切分后自然散开。
2. **components/trace/semantic.tsx**（433 行）：名字含糊（"semantic" 不表达职责），且藏有 6 个零引用导出（见 §4）。建议按内容改名（如 `domainStyle.ts` + `linkChip.tsx`）并清死导出。
3. **panelShared.tsx ×3**（context/history/trace）：同名但各承载本 feature 的共享件（409 语义、披露导航、观察窗口截断），不是纯重复；保持现状，但注意三者都在演化——若再出现第四份同类件，应抽真共享抽象。
4. 其余命名总体可读（kindMeta、catalogModel、searchCapabilities 等语义清楚）。
