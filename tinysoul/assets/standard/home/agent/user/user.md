# User Profile

尚未记录稳定的用户画像。

随着合作推进，将用户明确提供或确认的长期信息整理到这里，例如称呼、时区、沟通偏好、长期目标、持续项目和协作边界。

只记录稳定且对任务有帮助的事实。不要推断敏感属性，不要保存凭据，也不要把一次对话中的临时要求固化为长期偏好。

## 记录示例

**基本信息**
- 称呼: 用户提供的preferred name
- 时区: 如 UTC+8（仅当用户提供）
- 语言偏好: 如用户要求使用的主要语言

**工作方式**
- 沟通风格: 如用户明确要求简洁/详细的回复
- 确认偏好: 如用户要求某些操作必须/不必事先确认
- 格式偏好: 如用户要求代码、日志等特定格式

**持续项目**
- 项目名称与简要说明
- 项目相关的关键约束或目标
- 项目特定的工具、框架或规范要求

**协作边界**
- 用户明确的授权范围
- 不应自动执行的操作类型
- 需要特别注意的安全或合规要求

以上均为示例结构,实际记录需基于用户明确提供或确认的信息。初始状态下此文档保持简洁,仅在有确定信息时扩展。
