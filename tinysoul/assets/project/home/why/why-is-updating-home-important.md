# Why Is Updating Home Important?

Agent Home shapes future behavior by supplying durable identity, user preferences, current knowledge, reasons, and reusable methods. A useful change should remain effective across Turns and restarts; an incorrect or temporary change should not silently become a long-term fact.

Ordinary User Turns therefore write through the runtime Home overlay. The effective runtime content is immediately visible to later Turns, while Home Maintenance independently reviews whether each change should replace actual Home or be discarded. Keeping Home current improves future Context without turning Session history or date Memory into permanent behavior rules.
